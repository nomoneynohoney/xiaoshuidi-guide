# 小水滴破圈指南

**一人找一位台北市民、還不支持 Puma 的朋友，在 LINE 上一對一聊聊，請他給沈伯洋一次說明的機會。**

> 本指南由支持者自發製作，非沈伯洋競選總部官方文件。

**👉 [PDF 版](https://nomoneynohoney.github.io/xiaoshuidi-guide/xiaoshuidi-guide.pdf)**

## 這是什麼

給沈伯洋支持者使用的破圈溝通指南，用於 2026 台北市長選舉（投票日 11/28）。目標不吵架，好好講政見。

## 內容

1. 先認識 Puma：沈伯洋是誰（經歷、HEART 五大政見主軸、上任 100 天三件事）
2. 四大心法
3. 一段聊天的五個步驟
4. 市政議題卡（8 個議題：Puma 怎麼做、為什麼，附現任做法參考）
5. 常見反應怎麼接
6. 我們不是候選人：答不出來，就交給 Puma 本人
7. 紅線
8. 聊天流程圖

## 使用前請注意

- 重點是介紹 Puma 的政見，不批評、不標籤化現任。完整政見以 <https://puma.taipei/policies> 為準。
- 朋友的問題和想法記在自己手機裡就好，不要整理成名單、截圖對話傳出去。
- 投票日前十天內不發布、不轉傳民調；11/28 投票日當天不拉票。

## 修改與轉製

- `index.html`：PDF 的原始檔
- `小水滴破圈指南.md`：純文字版

修改 `index.html` 後用 Chrome 輸出 PDF：

```sh
google-chrome --headless --no-pdf-header-footer --print-to-pdf=xiaoshuidi-guide.pdf index.html
```

或直接用瀏覽器開啟 `index.html`，選「列印 → 另存為 PDF」。
